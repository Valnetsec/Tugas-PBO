# Java Inheritance

## 🧩 Konsep yang Dipelajari

- **Inheritance:** menggunakan `extends` untuk mewarisi atribut dan method dari superclass.
- **Constructor:** menginisialisasi objek melalui parameter.
- **Method Overriding:** mengimplementasikan ulang method `printInfo()` sesuai kebutuhan setiap subclass.
- **Encapsulation:** mengelola atribut dan menyediakan getter/setter.
- **Scanner:** menerima input dari pengguna melalui terminal.
- **Control Flow:** menggunakan `switch-case` dan `while` untuk mengelola menu program.

## 📂 Struktur Class

```text
Bentuk
├── BujurSangkar
└── Lingkaran
    └── Silinder
```

| Class | Deskripsi |
|---|---|
| `Bentuk` | Superclass yang menyimpan atribut warna dan method `printInfo()`. |
| `BujurSangkar` | Subclass untuk menghitung luas bujur sangkar. |
| `Lingkaran` | Subclass untuk menghitung luas lingkaran. |
| `Silinder` | Subclass dari `Lingkaran` untuk menghitung volume silinder. |
| `Main` | Entry point program yang mengelola input pengguna dan menu. |

## 🧮 Rumus Perhitungan

- **Bujur Sangkar:** luas = sisi × sisi
- **Lingkaran:** luas = π × radius²
- **Silinder:** volume = luas alas × tinggi
